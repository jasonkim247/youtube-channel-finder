# V2.2 Search Presets

This file documents the expanded discovery presets added for the next search pass.

- `core`: broad Korean daily-vlog terms
- `daily`: daily life, weekend, living-alone, and routine terms
- `food`: home meal, solo meal, stew, and cooking terms
- `localized`: Japanese-caption / localization-oriented terms
- `all`: balanced cross-category mix

The intended broad pass uses the `all` mix with both `relevance` and `date` search orders, while keeping enough search-call headroom for follow-up experiments.
